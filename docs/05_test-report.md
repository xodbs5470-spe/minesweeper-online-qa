| 환경 | Windows 11 Pro, Chrome 158 (주) / Edge 157 (교차 확인), 1920 x 1080 |

결론: 표준 모드 초급의 핵심 기능(칸 열기, 깃발, 화음, 타이머, 승패 판정, 재시작)에서 결함은 발견되지 않았다. 다만 도움말에 기본 정보와 일부 규칙이 빠져 있어 문서 보완을 제안한다.

## 3. 명세 미기재 항목
도움말에 규칙이 없어 결함으로 판단하지 않은 동작이다.

| 항목 | 관찰 결과 | 관련 TC |
|---|---|---|
| 초급 보드 크기, 지뢰 수 | 11 x 11, 지뢰 10개 | TC-001 |
| 첫 클릭 | 표준 모드에서는 첫 클릭에도 지뢰가 열릴 수 있음 | TC-021 |
| 패배 조건과 화면 | 지뢰 칸을 열면 패배, 모든 지뢰 위치와 잘못 꽂은 깃발(빨간색) 표시 | TC-022, 023 |
| 새로고침 중 타이머 | 새로고침에 걸린 시간도 타이머에 포함 | TC-033 |
| 탭 전환 중 타이머 | 다른 탭에 있던 시간도 타이머에 포함 | TC-034 |

## 4. 확인 후 결함에서 제외한 항목
| 항목 | 내용 | 판단 |
|---|---|---|
| 좌우 동시 클릭 시 깃발이 꽂힘 (TC-038) | 화음 설정(인접한 사각형 활성화)이 "좌클릭"일 때 발생. 우클릭은 깃발로 처리되고 좌클릭은 깃발 칸이라 무시됨. 설정을 "좌우클릭"으로 바꾸면 좌우 동시 클릭으로 화음이 정상 실행됨 (TC-041) | 설정에 따른 정상 동작 |

## 5. 개선 제안
1. **도움말에 초급 기본 정보 추가**: 보드 크기, 지뢰 수, 패배 조건이 도움말에 없다.
2. **첫 클릭 규칙 명시 또는 보호 옵션 제공**: 표준 모드에서 첫 클릭에 패배할 수 있다는 점이 안내되지 않는다. 많은 지뢰찾기 게임이 첫 클릭을 안전하게 보장하므로 사용자가 결함으로 오해할 수 있다.
3. **타이머 정책 명시**: 새로고침이나 탭 전환 중에도 타이머가 흐른다는 점을 도움말에 적으면 기록 관련 문의를 줄일 수 있다.
4. **화음 용어 통일**: 도움말은 "화음", 설정 화면은 "인접한 사각형 활성화"라고 써서 설정을 찾기 어렵다.

## 6. 한계
- 표준 모드 초급, 비로그인, PC 마우스 입력만 테스트했다. 중급 이상, 추측없이 모드, 모바일, 로그인 기능은 범위에서 제외했다.
- 보드가 무작위라서 특정 상황(첫 클릭 지뢰, 화음 조건)은 여러 판을 반복해 재현했다.
- 일부 케이스는 실제 결과가 "기대 결과와 같음"으로만 기록되어 세부 관찰 내용이 없다.
