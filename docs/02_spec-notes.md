# 게임 규칙 정리 (명세)

출처: 도움말 > 게임플레이 (https://minesweeper.online/ko/help/gameplay)

## 초급 기본 정보
- 보드 크기: 도움말에 없음 → 탐색 결과 11 x 11
- 지뢰 수: 도움말에 없음 → 탐색 결과 10개
- 초급 3BV 최소값: 5 (이보다 낮은 판은 시간 랭킹에 기록 안 됨) (출처: 도움말)

## 조작
- 좌클릭: 칸을 연다 (도움말에 직접 설명은 없음. "모든 셀을 열면 승리"에서 유추)
- 우클릭: 지뢰로 의심되는 칸에 깃발 표시 (출처: 도움말)
- 열린 숫자 칸 클릭 시: 숫자와 주변 깃발 수가 같으면 주변 칸을 모두 연다 (화음/코드). 방식은 설정에서 변경 가능 (출처: 도움말)
- 스마일(웃는 얼굴) 버튼 또는 스페이스바: 새 게임 시작 (출처: 도움말)

## 화면 표시
- 남은 지뢰 수: 왼쪽 (출처: 도움말)
- 타이머(초 단위): 오른쪽 (출처: 도움말)
- 한 게임 최대 시간: 10시간 (출처: 도움말)

## 규칙
- 첫 클릭: 도움말에 없음 (팁: "모서리에서 시작하라"만 있음)
  - 탐색 결과: 표준 모드에서는 첫 클릭도 지뢰일 수 있음 (03_exploratory-notes 참고)
- 승리 조건: 지뢰가 없는 모든 칸을 연다 (출처: 도움말)
- 패배 조건: 도움말에 없음 → 탐색 결과 지뢰 칸을 열면 패배

## 도움말에 명시되지 않은 것 (궁금한 점)
- ~~초급 보드 크기와 지뢰 수는?~~ → 11 x 11, 지뢰 10개
- ~~첫 클릭은 항상 안전한가?~~ → 탐색 결과 안전하지 않음 (표준 모드)
- ~~지뢰를 열면 어떻게 표시되는가?~~ → 타이머 정지, 지뢰 위치 표시, 잘못 꽂은 깃발은 빨갛게 표시
- ~~타이머는 언제 시작하고 언제 멈추는가?~~ → 첫 클릭 시 시작, 패배·승리 시 정지
- ~~깃발을 지뢰 수보다 많이 꽂으면 남은 지뢰 수가 음수가 되는가?~~ → 음수로 표시됨
- ~~깃발이 꽂힌 칸을 좌클릭하면 열리는가?~~ → 좌클릭은 반응 없음. 우클릭하면 깃발이 해제됨
- 숫자와 깃발 수가 다른데 숫자 칸을 클릭하면 어떻게 되는가? → 탐색 단계 미확인. 일반 지뢰찾기 기준으로는 깃발이 적거나 많으면 화음이 실행되지 않음 → 테스트 케이스로 검증
- ~~깃발을 잘못 꽂은 상태에서 화음을 하면 지뢰가 터지는가?~~ → 깃발 수가 숫자와 같으면 화음이 실행되어, 깃발 없는 진짜 지뢰 칸이 열리며 패배
- ~~우클릭을 반복하면 물음표(?) 표시가 나오는가?~~ → 나오지 않음 (깃발 ↔ 해제만 반복)
- ~~승리 시 남은 지뢰에 깃발이 자동으로 꽂히는가?~~ → 자동으로 꽂힘, 타이머 정지
