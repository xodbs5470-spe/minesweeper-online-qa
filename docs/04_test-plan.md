# 테스트 계획

## 1. 목적
Minesweeper Online 표준 모드 초급이 도움말 규칙과 탐색 플레이에서 확인한 동작대로 작동하는지 검증한다.

## 2. 범위
### 포함
| 영역 | 내용 |
|---|---|
| 보드 | 초급 보드 크기, 지뢰 수, 초기 상태 |
| 칸 열기 | 좌클릭, 빈칸 자동 열림, 숫자 표시 |
| 깃발 | 우클릭 꽂기/해제, 남은 지뢰 카운터 |
| 화음 | 숫자 칸 클릭 시 주변 칸 열기 |
| 타이머 | 시작, 정지, 초기화 |
| 승리 / 패배 | 판정 조건, 종료 화면 표시 |
| 재시작 | 스마일 버튼, 스페이스바 |
| 화면 구성 | 카운터, 타이머, 버튼 위치 |
| 예외 상황 | 새로고침, 탭 전환, 마우스 입력 예외, 화면 확대, Edge 교차 확인 |

### 제외
- 중급, 고급, 사용자 지정 난이도
- 추측없이(NG) 모드 등 표준 외 모드
- 로그인, 랭킹, 통계, 공유, 힌트, 편집기
- 모바일 / 터치 입력, Chrome·Edge 외 브라우저
- 성능, 보안, 서버 부하

## 3. 참고 문서
- `01_test-environment.md`: 테스트 환경
- `02_spec-notes.md`: 도움말 규칙 정리
- `03_exploratory-notes.md`: 탐색 플레이 결과

## 4. 테스트 방법
- 수동 블랙박스 테스트. 테스트 케이스(`test-cases/test-cases.csv`)를 순서대로 실행한다.
- 기대 결과의 근거 우선순위는 아래와 같다. 각 케이스의 비고에 근거를 적는다.
  1. 도움말
  2. 탐색 플레이 결과
  3. 일반 지뢰찾기 관례 (도움말과 탐색에서 확인되지 않은 동작)
- Fail이면 스크린샷을 `screenshots/`에 `TC-번호_설명.png`로 저장한다.

## 5. 테스트 환경
`01_test-environment.md`와 같다. (Windows 11 Pro, Chrome 158 / Edge 157, 1920 x 1080, 비로그인)

## 7. 시작 / 종료 기준
- 시작: 테스트 케이스 작성 완료, 테스트 환경 준비 완료
- 종료: 모든 테스트 케이스 실행 완료, Fail 항목 결함 리포트 작성 완료

## 8. 결과 분류
| 분류 | 의미 |
|---|---|
| Pass | 기대 결과와 같음 |
| Fail | 기대 결과와 다름 → 결함 리포트 작성 |
| 명세 미기재 | 도움말에 규칙이 없어 결함으로 볼 수 없는 동작 (예: 첫 클릭 안전 여부) |
| 개선 제안 | 결함은 아니지만 사용성 개선 여지가 있는 동작 |

### 결함 심각도
| 심각도 | 기준 |
|---|---|
| 높음 | 승패 판정 오류, 게임 진행 불가 |
| 중간 | 카운터·타이머 오표시, 조작이 기대와 다름 |
| 낮음 | 화면 표시, 문구 등 사소한 문제 |

## 9. 위험 요소
- 보드가 무작위라서 특정 상황(화음 조건, 첫 클릭 지뢰 등)을 바로 재현하기 어렵다. → 여러 판을 반복하고, 상황이 나오면 스크린샷으로 기록한다.
- 사이트가 업데이트되면 동작이 바뀔 수 있다. → 테스트 날짜와 브라우저 버전을 기록한다.
