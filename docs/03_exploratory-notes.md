# 탐색적 테스트 메모

## 화면 구성
- 왼쪽 상단: 남은 지뢰 수 카운터
- 오른쪽 상단: 게임 시작 후 지난 시간 타이머
- 상단 가운데: 다시하기(스마일) 버튼
- 하단 버튼: 공유하기, 힌트, 편집기에서 편집하기, 스크린샷
  - 힌트를 사용하면 "힌트 끄기" 버튼이 나타남
- 중앙: 지뢰판
- 추측없이(NG) 모드에서는 첫 시작 지점이 표시됨

## 플레이하며 관찰한 동작
- 지뢰가 아닌 칸에 깃발을 꽂은 상태에서는 지뢰를 다 찾은 것처럼 보여도 게임이 끝나지 않음
  - 도움말의 승리 조건("지뢰가 없는 모든 칸을 연다")과 일치. 깃발은 승리 조건이 아님 → 명세대로 동작
- 표준 모드에서는 첫 클릭이 안전하지 않음 (첫 클릭에 지뢰가 터질 수 있음)
  - 도움말에 첫 클릭 규칙이 없으므로 결함이 아니라 "명세 미기재" 항목으로 기록
- 초급 보드는 11 x 11, 지뢰 10개
- 타이머는 첫 클릭 시 시작
- 지뢰를 밟으면
  - 타이머가 멈춤
  - 모든 지뢰 위치가 표시됨
  - 잘못 꽂은 깃발은 빨갛게 표시됨
- 깃발을 지뢰 수보다 많이 꽂으면 남은 지뢰 카운터가 음수로 표시됨
- 깃발 칸 좌클릭: 반응 없음 / 우클릭: 깃발 해제
- 우클릭을 반복해도 물음표(?)는 나오지 않음
- 화음(숫자 칸 클릭)
  - 깃발 수 = 숫자, 깃발 중 하나가 잘못 꽂힘 → 깃발 없는 진짜 지뢰 칸이 열리며 패배
  - 깃발 수 < 숫자, 깃발 수 > 숫자 → 탐색 단계에서 미확인 (테스트 케이스로 검증)
- 승리(지뢰 제외 모든 칸 열기) 시 남은 지뢰에 깃발이 자동으로 꽂히고 타이머 정지

## 테스트 케이스로 넘길 항목
- 첫 클릭 동작 (표준 모드는 첫 클릭이 지뢰일 수 있음)
- 타이머: 첫 클릭 시 시작, 승리·패배 시 정지
- 남은 지뢰 카운터: 깃발 꽂기/해제 시 증감, 지뢰 수보다 많이 꽂으면 음수 표시
- 깃발: 우클릭으로 꽂기/해제, 깃발 칸 좌클릭 무반응, 물음표 없음
- 화음: 깃발 수 = 숫자(정상/잘못된 깃발), 깃발 수 < 숫자, 깃발 수 > 숫자
- 패배 화면: 지뢰 위치 표시, 잘못 꽂은 깃발 빨간 표시
- 승리 화면: 남은 지뢰 자동 깃발, 타이머 정지
- 다시하기(스마일) 버튼, 스페이스바 재시작

## 이상하거나 궁금했던 점
- [범위 밖] 추측없이 모드에서 어쩔 수 없이 찍어야 하는 상황이 생기면 어떻게 동작하는지 (도움말: "추측할 필요가 없다"고 명시 → 찍어야 하는 상황이 나오면 결함 후보)
